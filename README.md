# Conveyor Sorting & Palletizing System — PLC/HMI

![PLC/HMI Conveyor System](./Screenshot%202026-09-27%20204846.png)

## Overview
Built and simulated a weight-based conveyor sorting and palletizing system using Siemens S7-1214C, TIA Portal, PLCSIM, and Factory I/O.


## My contribution
- Implemented ladder logic for item routing, counting, and conveyor sequencing.
- Developed a four-step pick-and-place sequence.
- Designed a KTP700 HMI for operator controls and live system status.
- Validated the control workflow in the PLC/HMI simulation environment.


## Technologies
Siemens S7-1214C · TIA Portal · PLCSIM · Factory I/O · Ladder Logic · KTP700 HMI
